设置 · GitHub 同步

本页是纯前端版（GitHub Pages），没有服务端。 Token 只保存在当前浏览器的 localStorage 里，直连 api.github.com，不会提交到任何仓库。 换电脑/换浏览器需重新填写；公共电脑上请不要保存 Token。

几个人共用、谁都不想填 Token？ 填写下面的代理地址即可：Token 由服务端代持， 浏览器里没有任何凭据。配置好后点 🔗 一键链接，把链接发给同组的人 —— 他们打开一次就永久生效。

不想每台设备都手填？配置好后点 🔗 一键链接，把生成的链接存成书签， 换设备时打开这一条链接即可自动完成配置（凭据放在 # 片段中，不会发给服务器，也不会进仓库）。 该链接等价于密码，勿外发、勿截图。

不用代理时才需要 Token，且需要 repo 权限（私有仓库读写）。建议用 Fine-grained Token，仅授权这一个仓库。

数据仓库是独立于本页代码仓库的私有仓库，只用来存 prompts.json。

捕捉页的 AI 生成（可选）：填了下面的 Key，「✨ 捕捉」就会用大模型把素材提炼成 提示词 / Agent / 编排；留空或调用失败则自动回退到本地离线生成（不需要任何 Key）。 Key 只存在本机浏览器，不会上传、不会写进仓库。
